WCW.exe 받기
  • 1다운로드 창에 경고 뜨면 "유지" 클릭
  • 2받은 파일 실행 (설치 필요 없음)
  • 3파란 화면 뜨면 "추가 정보" → "실행" 클릭
  • 4우측 상단 위젯 버튼으로 원하는 거 추가

1인 개발자가 만든 무료 앱이라 아직 마이크로소프트 인증서가 없어서 뜨는 경고예요. 바이러스가 아니니 안심하고 진행하셔도 돼요.
